# متجر تفانين (Tafaneen)

## نظرة عامة

متجر تفانين هو متجر إلكتروني متخصص في بيع الكتب والقرطاسية والأدوات المكتبية والفنية. تم تطويره باستخدام أحدث التقنيات لتوفير تجربة تسوق ممتازة للمستخدمين.

## اسم الصفحة الرئيسية

الصفحة الرئيسية للموقع تسمى `Index` وتوجد في المسار `src/pages/Index.tsx`.

## التقنيات المستخدمة

### الواجهة الأمامية
- **React 18.3.1**: مكتبة JavaScript لبناء واجهات المستخدم
- **TypeScript**: لغة برمجة تضيف أنواع البيانات الثابتة إلى JavaScript
- **Tailwind CSS**: إطار عمل CSS للأدوات المساعدة
- **React Router**: للتوجيه في تطبيق الصفحة الواحدة
- **Radix UI**: مكتبة مكونات واجهة مستخدم منخفضة المستوى
- **Lucide React**: مكتبة الأيقونات
- **React Hook Form**: للتعامل مع النماذج
- **TanStack Query**: لإدارة حالة الخادم والبيانات

### الخلفية والقواعد
- **Supabase**: منصة BaaS (Backend as a Service) توفر قاعدة بيانات والمصادقة

### أدوات التطوير
- **Vite**: أداة بناء سريعة للتطبيقات الحديثة
- **ESLint**: أداة فحص الكود
- **Playwright**: لإجراء الاختبارات من طرف إلى طرف (E2E)

## المكونات الرئيسية

### 1. الصفحة الرئيسية (Index)
تتكون الصفحة الرئيسية من:
- رأس الصفحة (Header)
- البانر الرئيسي (Hero)
- عرض الفئات (Categories)
- المنتجات المميزة (FeaturedProducts)
- شريط التنقل السفلي (BottomNav)

### 2. رأس الصفحة (Header)
يحتوي على:
- شعار الموقع
- أيقونات السلة والمفضلات والإشعارات
- شريط البحث المحسن (EnhancedSearch)

### 3. عرض المنتجات
- ProductCard: لعرض المنتجات بشكل فردي
- FeaturedProducts: لعرض المنتجات المميزة
- CategoriesPage: لعرض المنتجات حسب الفئة

### 4. سلة التسوق (Cart)
- عرض المنتجات المضافة
- حساب المجموع
- إتمام عملية الشراء

### 5. صفحة المنتج (ProductDetailsPage)
- عرض تفاصيل المنتج
- إضافة المنتج للسلة
- إضافة المنتج للمفضلات

### المتطلبات
